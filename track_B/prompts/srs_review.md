# T-A0 - SRS-разминка

Вход от оркестратора: номер урока и уже отсортированный список максимум из 5 карточек `id + front + back`. Оркестратор обязан сортировать `(due_lesson ASC, lapses DESC, id ASC)` до вызова агента. Агент не читает базу сам и не меняет порядок.

Правила:

1. Одним сообщением показать весь пакет с заголовком `[КАРТОЧКА]` и номерами 1-5. Для каждой строки показывать только `front`; `back` до ответа ученика запрещён. Инструкция: ответить на все номера одним сообщением, а если ответ неизвестен — написать `не помню`.
2. Оркестратор фиксирует `batch_issued_at` в момент показа сообщения и `initial_answer_received_at` при получении ответа. Разница — initial learner-active time. Любое время генерации/проверки между сообщениями исключается и не сокращает SRS.
3. Проверить все ответы за один проход. Дать по каждому номеру только `correct` либо короткое исправление из переданного `back`; не добавлять примеры или упражнения.
4. Если есть ошибки, одним сообщением запросить повтор только их номеров. Разрешён ровно один общий retry, целевой лимит — 2 learner-active минуты от `retry_issued_at` до `retry_answer_received_at`. После него блок закрывается независимо от результата.
5. Карточка получает `easy`, только если первоначальный ответ верен или retry успешен. Явное `не помню`, неверный ответ после retry или отсутствие ответа на показанный номер — `lapse`. Карточки, которые не вошли в пакет, возвращаются как `not_reviewed` и не меняются.
6. В конце вернуть один служебный блок для оркестратора:

```json
{"batch_size":5,"batch_issued_at":"ISO-8601","initial_answer_received_at":"ISO-8601","initial_active_sec":0,"retry_ids":[],"retry_issued_at":null,"retry_answer_received_at":null,"retry_active_sec":0,"srs_productive_sec":0,"model_wait_excluded":true,"timebox_observed":true,"results":[{"id":0,"result":"easy|lapse"}],"not_reviewed":[]}
```

Никаких последовательных выдач по одной карточке, параллельных SRS-агентов, дополнительных упражнений, карточек или советов.
