# WF-4 - Обзор семиурочного цикла (`weekly_review`)

Когда использовать: day 7 каждого семиурочного цикла (независимо от календаря).

Вход от оркестратора: данные последних 7 завершённых уроков из `lesson_sessions.json`, случаи ошибок из `error_events.json`, агрегированный `error_log.json`, `assessments.json`, записи `speaking_recordings.json` и статистика `srs_items.json`.

Системные правила роли (`weekly_review`):

1. Агент работает строго с переданным набором данных за последние 7 уроков (сам файлы не читает и не изменяет).
2. Сформировать компактный аналитический отчёт (markdown, до 300 слов):
   - Процент выполнения плана и сводка фактического продуктивного времени (`actual_learning_min`).
   - **Максимум 2 главных сигнала** (топ-2 повторяющиеся ошибки по `covered_grammar` на основе `error_events.json` + одно короткое упражнение-повтор по главной из них; ошибки `not_yet_covered` остаются только в статистике).
   - Один приоритетный фокус навыка на следующий 7-урочный цикл.
   - **Ровно одна замена (replacement adjustment)** в следующем цикле: никогда не добавлять работу поверх бюджета времени (чтобы что-то усилить, нужно что-то заменить).
   - Короткое фактическое резюме прогресса в реальных цифрах.
3. В конце ответа выдать служебный JSON-блок для оркестратора:
```json
{
  "add_focus": [],
  "remove": [],
  "grammar_drills": []
}
```
Ограничения JSON: в каждом массиве (`add_focus`, `remove`, `grammar_drills`) — **максимум 1 элемент**. Агент read-only.


## Контракт выполнения

Оркестратор передаёт track_B/local/lesson_contract.md вместе с today и analytics_contract. Его правила времени, неполного закрытия и происхождения данных обязательны. Квоты ниже — верхние границы; не превышать оставшееся время.

**Лимит (сокращается по оставшемуся времени) и сценарий `weekly_review`:** 20–25 мин основной review; Day 7 15 мин лёгкий sample/reading + 15 мин отчёт, общий бюджет 30 минут. Максимум два сигнала и одна замена, без новых заданий. W4/W8/W12: Day 6 benchmark монолог 2–3 мин + CAF, Day 7 EF SET отдельно в пределах бюджета либо отдельной согласованной процедурой.
