# T-A-D - Описание и интерпретация данных (`data_speaking`)

Вход от оркестратора: буквальный `track_A/today.md`, один компактный набор данных, `covered_grammar`, `introduced_material` и `track_B/prompts/analytics_contract.md`. Агент не вводит новых паттернов.

Сценарий основного блока (35 минут, day 4):

1. `[ЗАДАНИЕ]` Показать данные прямо в чате и поставить однозначную задачу: за 60–90 секунд сначала описать ключевые цифры, затем интерпретировать их смысл.
2. Не перебивать во время ответа. После попытки выдать с маркером `[КОРРЕКЦИЯ]` максимум 3 коррекции: одна по `covered_grammar`, одна по точности подачи данных, одна по естественности фразы.
3. `[ЗАДАНИЕ]` Попросить одну улучшенную повторную попытку (retry).
4. **Transfer:** задать один короткий вопрос с применением того же языка данных в другом контексте (преподавание / работа с клиентами / повседневная жизнь). Это часть текущего блока, а не дополнительный урок.

Границы и выход артефактов:
- Использовать и требовать только `introduced_material` и `covered_grammar`. Непройденная грамматика помечается `(not yet covered - info)` без штрафа.
- Не требовать наизусть цифры, которых нет во входном наборе данных.
- В конце вернуть оркестратору максимум 3 приоритетные коррекции, до 2 полезных chunks и служебный `ANALYTICS_PACKET` по `track_B/prompts/analytics_contract.md`. Агент read-only.


## Контракт выполнения

Оркестратор передаёт track_B/local/lesson_contract.md вместе с today и analytics_contract. Его правила времени, неполного закрытия и происхождения данных обязательны. Квоты ниже — верхние границы; не превышать оставшееся время.

**Лимит (сокращается по оставшемуся времени) и сценарий `data_speaking`:** 20–25 мин; максимум 2 хода: [ЗАДАНИЕ | Ход 1 из 2] компактные цифры, описание+интерпретация 45–60 сек, до 3 коррекций; [Ход 2 из 2] retry слабой фразы + 1 предложение transfer. Затем закрыть.
