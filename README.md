# English_Tutor — AI-система подготовки B2 → C1

Персональная мульти-агентная система изучения английского языка (B2 → C1) с фокусом на профессиональную презентацию, методическую защиту и B2B-продажу авторского образовательного AI-курса во Вьетнаме, работу с клиентами и свободный разговорный английский.

Система спроектирована как **файловое мульти-агентное рабочее пространство** с единым источником истины и работает по одному и тому же протоколу в любой среде: **OpenCode**, **OpenAI Codex**, **Claude Code**, **Cursor / Windsurf** или веб-чате с доступом к репозиторию.

---

## Быстрый старт (в любом ИИ-агенте)

### 1. Чтобы начать очередной урок по расписанию:
Напишите в чат одну фразу:
> **`Прочитай AGENTS.md и track_A/LESSON_START.md. Начинаем следующий урок строго по ним.`**
*(Если ваша среда — например, **OpenCode**, **Codex** или **Claude Code** — автоматически подгружает `AGENTS.md` / `CLAUDE.md`, достаточно короткой команды: **`Начинаем урок`**).*

### 2. Чтобы повторить пройденный материал после долгого перерыва (без сдвига номера урока):
Напишите в чат:
> **`Прочитай AGENTS.md и track_A/LESSON_START.md. У меня был перерыв, давай проведём урок-повторение пройденного (Refresher) по урокам 1–8.`**

### 3. Чтобы пожаловаться на проблему или внести правку в механику урока:
- **Прямо во время урока:** напишите своими словами: *«Запиши в корректировки урока: мне не нравится X, хочу чтобы было Y»* — агент запишет это в раздел `Pending` файла `Корректировки_урока.md` и продолжит урок.
- **В отдельном чате после урока (чтобы починить систему):** напишите:
  > **`Прочитай AGENTS.md (Сценарий Б), раздел "Текущий статус" в session.md и Корректировки_урока.md. Посмотри последний урок — мне не понравилось [X], давай исправим.`**

## Архитектура и единая точка входа (4 уровня)

Чтобы при смене приложения, IDE или нейросети правила урока никогда не «плыли», вся логика разделена на 4 канонических уровня:

| Уровень | Файл / папка | Роль в системе |
|---|---|---|
| **1. Устав** | `AGENTS.md` (и авто-указатель `CLAUDE.md`) | Глобальные жёсткие правила, антишум, таймбоксинг (40–50 мин, hard cap 60 мин), оркестрация и Git-дисциплина |
| **2. Старт урока** | `track_A/LESSON_START.md` | Компактный чек-лист старта (обычный урок или `Refresher` после перерыва) и закрытия урока |
| **3. Протокол цикла** | `track_B/local/protocol.md` | Правила 7-урочного цикла, формат `track_A/today.md`, режимы коррекции, закрытия урока и коммита в GitHub |
| **4. Канонические промпты** | `track_B/prompts/*.md` (12 ролей + `analytics_contract.md`) | **Единственный источник правды** по поведению каждого учебного блока |

### Как разные ИИ-агенты подключаются к проекту:
Все 12 учебных ролей имеют единые канонические имена во всех трёх директориях (`srs_review`, `grammar_lesson`, `check_grammar`, `tutor_speaking`, `reading_tutor`, `data_speaking`, `patterns_listening`, `pitch_coach`, `mock_pitch`, `check_monologue`, `check_monologue_caf`, `weekly_review`):
- **OpenCode:** автоматически читает корневой `AGENTS.md` и использует 12 read-only субагентов в `.opencode/agents/<role-kebab>.md` (`@srs-review`, `@grammar-lesson`, `@check-grammar`, `@tutor-speaking` и др.), которые напрямую читают `track_B/prompts/<role>.md` и `analytics_contract.md`.
- **OpenAI Codex:** автоматически читает корневой `AGENTS.md`, `.codex/config.toml` и 12 read-only ролей в `.codex/agents/<role>.toml`.
- **Claude Code:** автоматически читает `CLAUDE.md` → `AGENTS.md` → `track_A/LESSON_START.md` и вызывает субагентов (`Task` tool) либо работает в режиме строгой ролевой изоляции (`Single-Agent Fallback`) по `track_B/prompts/<role>.md`.
- **Cursor / Windsurf / веб-агенты:** читают `AGENTS.md` и `track_A/LESSON_START.md` и ведут блоки строго по `track_B/prompts/<role>.md`.

### Как работает синхронизация через GitHub:
- Все уроки и база данных (`track_A/` и `track_B/local/db/*.json`) ведутся последовательно в одной основной ветке **`main`**.
- В начале сессии агент делает `git pull --rebase`, а при закрытии урока (или после внесения патча) — автоматически делает `git add -A && git commit -m "Lesson N completed" && git push` в `main` (если вы используете облачного веб-агента, который создаёт временную ветку на задачу, в конце урока он создаёт Pull Request, который вы сливаете кнопкой `Merge pull request`).

## Структура репозитория

```text
English_Tutor/
├── AGENTS.md                        # Главные правила проекта и оркестрации (читается автоматически в OpenCode и Codex)
├── CLAUDE.md                        # Авто-указатель на AGENTS.md и track_A/LESSON_START.md для Claude Code
├── README.md                        # Описание репозитория и команд запуска
├── .gitignore                       # Исключения для Git (OS/IDE файлы, node_modules)
├── session.md                       # Оперативный журнал сессий и текущий статус проекта
├── План_реализации.md               # Мастер-план Track A / Track B и референс DDL для Supabase
├── Корректировки_урока.md           # Буфер pending-правок и реестр применённых патчей P1–P24
│
├── .codex/                          # Конфигурация и 12 read-only субагентов для OpenAI Codex
│   ├── config.toml
│   └── agents/*.toml
├── .opencode/                       # 12 read-only субагентов для OpenCode
│   └── agents/*.md
│
├── course_base/                     # Актуальная база знаний детского AI-курса (24 файла, read-only)
│
├── track_A/                         # Учебный процесс (Track A)
│   ├── LESSON_START.md              # Единая точка входа в новый урок (обычный или Refresher после перерыва)
│   ├── progress.json                # Номер урока + накопительные covered_grammar и introduced_material
│   ├── today.md                     # Контракт текущего дня (перезаписывается на каждый урок)
│   ├── logs/                        # Дневные отчёты (YYYY-MM-DD.md), _template_daily.md, diagnostics.md, session_history_1_34.md
│   ├── program/                     # program.json (12 недель / 84 урока) и course_base_index.md
│   ├── speaking/                    # baseline.md (стартовый срез говорения)
│   └── transcripts/                 # index.md (индекс исторических данных уроков 1–6)
│
└── track_B/                         # Сборка системы и база данных (Track B)
    ├── prompts/                     # Канонические промпты 12 ролей + analytics_contract.md
    ├── local/
    │   ├── protocol.md              # Канонический протокол 7-урочного цикла
    │   ├── median.js                # Скрипт расчёта медианы 3 прогонов CAF (без внешних зависимостей)
    │   └── db/*.json                # 7 JSON-таблиц: srs_items, lesson_sessions, daily_tasks, error_events, error_log, speaking_recordings, assessments
    └── research/                    # research_methodology.md, research_materials.md и pattern_bank_v2.md
```
